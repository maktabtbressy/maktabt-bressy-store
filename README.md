# 🛒 متجر مكتبة بريسي  | MAKTABT BRESSY STORE

متجر إلكتروني تفاعلي متكامل مخصص لتقديم واستعراض الخدمات البرمجية، الطباعة الإلكترونية، والمعاملات المستندية.

### 🔑 أهم المميزات:
* **واجهة مستخدم حديثة:** متجاوبة تماماً مع الشاشات والموبايل بدعم كامل للغة العربية (RTL).
* **نظام إدارة المنتجات:** إمكانية التصنيف بحسب الأقسام، التحكم في الكميات المتاحة، والأسعار.
* **سلة مشتريات ودفع ديناميكي:** دعم طرق دفع متعددة (فودافون كاش، انستا باي InstaPay) مع إمكانية إرفاق إيصال التحويل.
* **لوحة تحكم إدارية شاملة (Super Admin & Sub-Admins):**
  * متابعة وتحديث حالة الطلبات مع إرسال ملاحظات للعميل.
  * إدارة وسائل وأرقام الدفع.
  * إدارة الأقسام والمنتجات وتعديل الهوية البصرية.
  * التحكم في صلاحيات الأدمن الفرعي وحسابات العملاء.
* **دعم فني مباشر (Live Chat):** شات داخلي للتواصل المباشر بين العميل والإدارة.
* **نظام إشعارات لحظي:** للتنبيه بالطلبات الجديدة وتحديثات الحالة.
